# Центр решений для селлера WB/Ozon: лендинг

Одностраничный лендинг платформы, которая не показывает цифры, а объясняет, почему упала маржа и что делать.

- Лендинг: https://electrocow0-tech.github.io/seller-landing/
- Прототип платформы: https://electrocow0-tech.github.io/seller-decision-center/
- Описание прототипа: https://github.com/electrocow0-tech/seller-decision-center

Один файл `index.html` без сборки: стили и скрипты inline, шрифты с Google Fonts. Интерактивный разбор причины с тремя сценариями, переключатель светлой и тёмной темы, форма заявки без бэкенда. Проверен на 1440 px и iPhone 13 (390 px).

Данные в демо условные.
